# python_project--data-analyst
python_project--data-analyst

This PDF provides an analysis of the Titanic dataset, focusing on passenger demographics and survival rates. Key points include:

- Dataset Overview:

- Contains 891 entries with 12 columns, including PassengerId, Survived, Pclass, Name, Sex, Age, SibSp, Parch, Ticket, Fare, Cabin, and Embarked.
  
- Missing Values:

-   Significant missing data in Age (177 missing) and Cabin (687 missing).

- Descriptive Statistics:
  
  - Mean age: ~29.7 years.
    
  - Survival rate: 38.38%.
    
  - Majority of passengers were male (577 out of 891).
    
- Survival Analysis:

  - Higher survival rates for females and 1st-class passengers.
    
  - Visualizations show survival trends by gender, passenger class, and family size.
  
  - Other Insights: Fare and age distributions vary by class and survival status, with some data visualizations included.

The report highlights factors influencing survival, such as class and gender, and notes data limitations like missing values.
